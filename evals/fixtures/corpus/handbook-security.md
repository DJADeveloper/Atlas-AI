# Security Basics for Employees

## Accounts and access

All access uses single sign-on with hardware security keys; passwords alone
are never sufficient. Access requests go through the Okta catalog and expire
after 90 days of non-use.

## Laptops

Company laptops run managed disk encryption and automatic patching. Lost or
stolen hardware must be reported to security@meridianlabs.example within 24
hours so remote wipe can be triggered.

## Phishing

Report suspicious emails with the Report button in the mail client. The
security team runs quarterly phishing simulations; repeat clickers get a
friendly training session, not a reprimand.
